Week03: Learning about HTTP Request and Response

Task 1: Inspect HTTP Requests

The port on which the browser will open will be "http://127.0.0.1:5050/index.html"

Open Chrome DevTools (F12 → Network tab, or right-click on the page → Inspect → Network tab). Refresh the page and examine the requests for HTML.

    Answer the following:
  • What HTTP methods are used (GET, POST, etc.)?
  • What response codes do you see (200 OK, 404 Not Found, etc.)?
  • Look at the request and response headers. What information is included?

Task 2: Modify and Analyze URLs

    In your browser, manually add a query string to your page’s URL: http://127.0.0.1:5500/index.html?name=student&theme=dark

  1. Open DevTools (F12) → Network tab → Refresh the page if needed → Click on the request for index.html?name=student&theme=dark.
  2. Look at the Request URL to confirm that the full URL with query parameters is displayed.
  3. Look for a section named Query String Parameters under the Payload tab. What information can you see there?

Task 3: Investigating HTTP Caching

For this task, you will inspect your week03 project, a cached webpage that includes a static HTML, and a JavaScript file. Open it in Live Server (index.html) loading from your local server (http://127.0.0.1:5500/).

    Observe Caching in Action
  • Open DevTools → Network tab → Click Disable cache (top-left checkbox).
  • Refresh the page and note the Time column values.
  • Now, enable caching and refresh again.
  • Compare loading times. What changed?
    Investigate Cache-Control Headers
  1. Click on a file request in the Network tab.
  2. Look at the Response Headers section.
  3. Identify and interpret: Cache-Control, ETag, Last-Modified.

    4. Note: ETag (Entity Tag) is an HTTP response header used for caching and version control of a resource.
    It helps the browser know whether a file has changed on the server or not so it doesn’t need to download it again unnecessarily.
